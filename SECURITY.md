# Security Policy

## Supported Versions

We provide security updates and patches for the current release branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of Lake of Tears seriously. If you believe you have found a security vulnerability in Lake of Tears, please follow responsible disclosure guidelines and report it to us privately.

**Please do not report security vulnerabilities through public GitHub issues.**

### How to Report

Please send an email to:
- **Email:** [support@thelakeoftears.com](mailto:support@thelakeoftears.com)
- **Subject:** `[Security] Lake of Tears Vulnerability Report`

Please include the following information in your report:
- Type of vulnerability (e.g., authentication bypass, SQL injection, RCE, sensitive data exposure)
- Affected component (`ui/`, `backend/`, `pipeline/`, Docker Compose, Helm chart, etc.)
- Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue
- Potential impact and any suggested mitigations or patches

### Response Timeline

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment:** We will confirm the vulnerability and determine the severity and impact within 5 business days.
- **Fix & Release:** We will develop and test a fix, and coordinate a patch release as quickly as possible.
- **Disclosure:** We will publish a security advisory via GitHub once the patch is released, crediting the reporter if desired.

Thank you for helping keep Lake of Tears and our community secure!
