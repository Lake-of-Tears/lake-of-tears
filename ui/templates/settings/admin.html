Catalog Settings

Configure how catalog deletions behave across all workspaces.

When a workspace admin deletes a catalog it enters a grace period before permanent deletion. Set to 0 to disable soft delete — deletions will be permanent immediately.

days (0 = permanent deletion immediately)

Workspace Retention Settings

Configure the grace period before an inactive workspace and its catalogs are permanently purged.

When a workspace is marked inactive it enters a grace period. After this period it and all its catalogs are permanently purged. Set to 0 to disable workspace deactivation (requires immediate hard delete).

days (0 = disable inactive state)
